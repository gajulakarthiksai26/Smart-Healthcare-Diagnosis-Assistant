# Smart-Healthcare-Diagnosis-Assistant
1. Project Description
The Smart Healthcare Diagnosis Assistant is a machine learning-based application designed to predict possible diseases based on symptoms or clinical descriptions entered by the user.
The system uses Natural Language Processing (NLP) techniques to preprocess the input text and TF-IDF vectorization to convert text into numerical features. A Support Vector Machine (SVM) algorithm is used to predict the disease.
After predicting the disease, the application also suggests a suitable medical department for further consultation.
2. Features
•	User-friendly web application developed using Streamlit.
•	Accepts patient symptoms or clinical descriptions as input.
•	Performs text preprocessing using NLP techniques.
•	Converts text into numerical features using TF-IDF.
•	Uses a Support Vector Machine (LinearSVC) model for disease prediction.
•	Predicts diseases from 30 disease categories.
•	Suggests a suitable medical department.
•	Displays prediction results to the user.
•	Provides an educational medical disclaimer.

5. Installation Instructions
Step 1: Install Python
Download and install Python from:
https://www.python.org/downloads/
Step 2: Install Visual Studio Code
Download VS Code from:
https://code.visualstudio.com/
Step 3: Open the Project Folder
Open the project folder in Visual Studio Code.
Step 4: Install Required Libraries
Open the VS Code terminal and execute:
pip install pandas numpy nltk scikit-learn matplotlib seaborn wordcloud streamlit
Step 5: Download Required NLTK Resources
Run the following command in Python:
import nltk

nltk.download('punkt')
nltk.download('punkt_tab')
nltk.download('stopwords')
nltk.download('wordnet')


6. Execution Steps
Step 1: Open the Project Folder
Open the Smart-Healthcare-Diagnosis-Assistant folder in VS Code.
Step 2: Prepare the Dataset
Ensure that DataSet.csv is available in the project folder.
Step 3: Generate the Balanced Dataset
Execute:
python balance_dataset.py
This creates DataSet_balanced.csv.
If the balanced dataset is already available and up to date, this step can be skipped.
Step 4: Train the Machine Learning Model
Execute:
python model_train.py
This trains the SVM model and generates the required model files.
Step 5: Run the Web Application
Execute:
streamlit run app.py
Step 6: Enter Patient Symptoms
Open the local URL displayed in the terminal, enter symptoms or a clinical description, and click the prediction button.
The application displays the predicted disease and suggested medical department.

9. Disclaimer
This project is developed for academic and educational purposes only. The disease prediction generated by the machine learning model is not a professional medical diagnosis. The suggested medical department is only a general recommendation. Users should consult qualified healthcare professionals for proper medical examination, diagnosis, and treatment.

10. Conclusion
The Smart Healthcare Diagnosis Assistant demonstrates how Natural Language Processing and Machine Learning can be used to analyze patient symptom descriptions and predict possible disease categories.
The application uses TF-IDF feature extraction and a Support Vector Machine algorithm to generate predictions and suggest relevant medical departments. It provides a simple interface for exploring the use of machine learning in healthcare decision-support applications.
